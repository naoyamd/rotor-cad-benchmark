# 停止・折畳み・復帰と組立

## 状態と順序

1. **飛行／回転**: 5本の飛行ロックを係合、マスト位置決めピンを退避、パーク支持を収納。固定・回転RR-Sとピッチリンクは接続したまま。エラストマーがflap/lag/pitchを許容する。
2. **停止・位置決め**: 回転停止を確認し、方位0°へ位置決め。回転検出だけを構造保持に使わず、減速機側マストフランジの位置決め穴へ機械ピンを入れる。検出器・キー移送機構の実機定格/故障解析は未完了。
3. **準備**: ピッチを約0°へ合わせ、各翼をジャッキで水平へ戻してパーク支持ブロックを装着。マスト保持を確認して飛行ピンを320 mm引き抜く。引抜いたピンはガイド筒内に残す。これはロック解除をソフトウェアフラグだけに任せる設計ではないが、トラップドキー装置の製品選定は残る。
4. **収納移行**: 翼2→5→3→4の順で、それぞれ−72°、+72°、+36°、−36°。翼1は直進を維持。`FoldFraction` 0〜1を四区間に分けて同じ順序を再生する。翼を取り外さず全長のまま評価する。
5. **収納**: パーク支持とマスト固定を保持する。翼先端の甲板支持・風荷重用収納タイダウンの容量は本版で確定していない。このため収納時保持の要求全体は未完了。
6. **復帰**: 逆順で展開、各飛行ピンの係合を確認、ピッチリンクの長さと位相を検査、支持ブロックを退避、最後にマスト固定を解除。インターロックの負の試験は実機安全認証とは区別する。

## 組立と整備性

- マストと機体側キャリアは別の反力経路。固定案内筒を取り付け、上下のブッシュを備えた一体球面スライダを差し込む。
- スワッシュ固定側は左右分割ソケットを球の周囲で閉じる。分割面、貫通穴、締結包絡をCADに持つ。レース座・ブッシュの公差とボルト予圧は発注仕様の未解決項目。
- 固定内輪に転動体とセパレータを配列し、外輪の上下半体を取り付けて回転リングと締結する。外輪の溝切れ目の接触応力・疲労・動定格は未検証。
- ロッドエンドは球の穴にピンを通し、スペーサを介して両側耳で支持する。頭と保持部の包絡を示す。球面外輪の加締め/分割組立の製法と市販品定格は確定していない。
- 翼根カフ、ホーン、ダンパー耳、折畳みクレビス間の固定接合をCADで追跡できる。固定接合の重なりは接合意図を示すが、これだけで鍛造・ボルト接合・溶接の強度を証明しない。未確定接合は接触台帳に残す。
- 折畳みヒンジと飛行ピンは別部品。ピン引抜き高さを確保するが、全工具・作業者アクセスと全締結の抜け止め完備を宣言する段階には達していない。

## 次の初期設計ゲートに必要な情報

重要なのは外観の追加ではなく、(1)弾性支持の圧縮/せん断/保持・接着仕様、(2)スワッシュ回転軸受の組合せ荷重と速度定格、(3)翼桁と金属取付の保持容量、(4)空力ピッチモーメントを含む反力包絡、(5)固定接合の製法・断面確定、(6)全域干渉の残検査、(7)収納時タイダウンと物理インターロックの完成である。これらを将来の認証試験だけの問題として扱わない。
