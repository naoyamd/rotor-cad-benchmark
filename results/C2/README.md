# Rotor C2 公開パッケージ

このフォルダは `rotor-design-v2` の最終成果物を、C2ページと同じ公開リポジトリ用に複製したものです。`final-report.md` にある「GitHubへは公開していない」は、設計成果物を作成した時点の記録であり、この公開パッケージの状態を指しません。

`verification/cad-checks.json` の入力ファイルパスは、ローカル環境を公開しないため相対ファイル名へ置き換えています。対応するハッシュを `verification/manifest.sha256` に更新し、原本のFCStd/STEPや検証結果の内容は変更していません。
