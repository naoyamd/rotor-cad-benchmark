# Rotor C1 engineering design review

作成日: 2026-10-25（America/Los_Angeles）
対象: この C1 スナップショットの設計基準、FreeCAD生成コード、保存済みCAD、`verification/numerical.json`

## 判定

- **G0: 完了。** 対象境界、方式、座標、主要仮定、参照範囲を記録している。
- **G1: 暫定版。合格していない。** 構造材料の許容値、球面エラストマー/回転軸受の定格容量、複合材継手の荷重伝達根拠がない。
- **G2: 未達。** 有限リンクの数値サンプルは良好だが、全作動域のCAD干渉・隙間・状態遷移は未検証。
- **G3: 未達。** 本成果物は工学候補と再生成可能な概念CADであり、製作図、耐空性、飛行安全性、認証の証明ではない。

この判定は `design-basis.md` の C1/G1暫定版と、元仕様の「強度を左右する材質・最大荷重・重要継手容量が未決定なら初期設計完了としない」という境界に従う。

## 1. 成果物と証拠の範囲

設計入力は、直径18.60 m、質量15,600 kg、5枚72°等配の単一メインローターである。これらは課題シナリオであり、AW101の実機部品寸法・材料・性能をコピーしたものではない。方式の参照は `../../SOURCES.md` のS1–S5に限定する。

現行コードは `src/mechanism.py` に力学・有限リンク計算、`src/build.py` にFreeCAD形状生成を集約する。`P`辞書を共有パラメータ源とし、保存状態は `rotor-neutral.FCStd/STEP`、`rotor-max-input.FCStd/STEP`、`rotor-folded.FCStd/STEP`、`rotor-parked.FCStd/STEP` である。`verification/cad-checks.json` は4状態の新規プロセスnative/STEP検証を含むが、状態間の連続遷移や保持容量を証明するものではない。

BOMは機能部品145件（境界用 `AirframeEnvelope` を除く）を含む。現行フォークのアセンブリは235ソリッドで構成される。部品数・ソリッド数は設計成立性や容量の証明ではない。

球面エラストマーの想定荷重経路は、翼等価桁 → 折畳み取付/ピン → カフ → 内レース → 圧縮積層 → 外レース → ハブ → 反対翼である。推力は翼支持からハブ、マスト、減速機境界へ、トルクはマストからハブ、支持・ダンパー・カフを通って翼へ流す。操縦反力は翼ねじり、ホーン、ピッチリンク、回転リング、回転軸受、非回転リング、3アクチュエータ、機体へ流す。これらは荷重経路の候補であり、容量を検証済みとはしない。

## 3. 有限リンクとスワッシュプレート

### 機構候補

- 非回転側は固定案内スリーブ上の上下スライダと球面支持を用い、軸方向移動と2方向傾斜を表現する。
- 最新の `mechanism.py` はスワッシュ中心 `z=1100 mm`、ロータ側接続を `swash_joint_z=100 mm` とする raised-lug配置を使う。旧い「中心1200 mm・接続0 mm」の配置ではなく、実装側の分離した高さを基準にする。
- 3本のサーボ接続を120°配置し、回転側リングを同軸の概念転がり軸受で支持する。
- 各翼は外輪、積層エラストマー、内レース、カフ、ピッチホーン、固定長の球面端ピッチリンク、ラグダンパー、折畳みヒンジ、飛行ロックを持つ。
- `horn_x=600 mm` の前後オフセットを採用した。初期配置で見られた約7.37°級の結合を抑える設計変更であり、現行 `numerical.json` では宣言したサンプル格子の最大複合誤差が0.16223°まで低下している。7.37°は旧配置との設計比較値であり、現行JSONの別計測値ではない。

### 数値証拠

`verification/numerical.json` の証拠は次のとおり。

- 方位12°刻み: 3,600サンプル、閉路残差 `4.55e−13 mm`、非結合ピッチ誤差 `0.05661°`、最小レバー腕 `235.665 mm/rad`。
- 方位6°刻み: 7,200追加サンプル（JSONの累積表示は10,800 = 3,600 + 7,200）、同じ閉路残差・最小レバー腕。
- 複合入力の最大ピッチ誤差 `0.16223°`、ピッチ範囲 `5.0318…19.1620°`。
- 3入力→5翼ピッチのJacobianは階数3、条件数 `1.41378`。
- CAD側でもneutral/max-input/folded/parkedの4状態について、実形状のボール中心閉路とpitch測定を独立に照合している。これは選択状態の証拠であり、全作動域、連続入力領域、リンク端の全ミスアライメントを証明するものではない。

## 4. 荷重・保持・構造境界

`loads()` のスクリーニング値は、遠心力474.4 kN/枚、マスト等価断面の参考von Mises値84.0 MPa、折畳みピン二重せん断62.7 MPaである。`engineering.json` の不確かさ包絡では翼保持要求1.033 MN、折畳みピン二重せん断91.05 MPa、折畳みクレビス面圧151.95 MPa、エラストマー投影圧縮12.15 MPa、リンク軸力30 kN仮定、Euler座屈荷重117.0 kNを示す。これらは鋼E=200 GPa、指定断面、静的係数1.5などの仮定から得た名目値で、許容応力、疲労、ピン曲げ、面圧定格、接着剥離、損傷許容を含まない。

球面積層はCAD上の物理形状と等価剛性を分けて扱う必要がある。現在の `Kpitch/Kflap/Klag` は自由関節を正当化する値ではなく、初期縮約モデル用の要求案である。外輪・内レース・スピンドル・折畳みロックについて、遠心荷重、推力、曲げ、トルク、ダンパー反力を同じ荷重ケースで釣り合わせる計算は未完了である。

特に未解決なのは、球面エラストマーの温度・周波数・経年・接着耐久、回転軸受の組合せ荷重容量、複合材スパーから金属カフへの荷重伝達、飛行ロックの単一故障時保持である。ダンパーは実ブラケット腕長約0.379 m、32 kN·s/mで再計算され、正常ζ=0.1138、50%劣化ζ=0.0569、質量+20%・剛性+50%・劣化の複合感度ζ=0.0424となった。いずれもbasisの暫定目標（正常0.08、劣化0.04）を上回るが、係数は仮定であり、温度/速度依存と全機連成は未検証である。これらが未確定のため、CADの寸法から「保持できる」「飛行できる」とは言わない。

## 5. 折畳み、状態、組立・サービス

折畳みは停止方位0°、根元折畳み軸1,500 mm、角度 `[0, −72, +36, −36, +72]°`、ピッチ/フラップ/ラグ0を候補とする。`FlightLock` は通常位置から320 mm引き抜いてから折畳み形状を生成する。4状態の折畳み/収納ファイルは保存され、折畳み幅は固定Y軸投影で`3503.868 mm`だった。全翼の保守的XY包絡経路436サンプルでは、サンプル間運動境界を差し引いた連続下限`630.362 mm`を得た。ただし根元ロック/タン、ヘッド、リンク、機体包絡はこの幅/経路証拠の対象外である。ロック保持容量、リテーナ、誤操作防止、残留回転の検出はまだ未検証である。

要求する状態は、飛行、停止・方位位置決め、折畳み準備、ヒンジ解放/移行、収納、復帰である。飛行中は折畳みヒンジを構造ロックで橋渡しし、アクチュエータだけを保持部にしない。停止時はマストを機械的に位置決めし、翼をパーク支持へ移してからロックを解除する。neutral/max-input/folded/parkedの保存形状は存在するが、状態間の連続経路、機械的停止、残留回転検出、収納保持容量は未検証である。現行CADには境界用機体包絡（X±6500、Y±1800、Z=−3000…0 mm）があるが、実機胴体・甲板・工具作業空間ではない。

組立上は、マスト/取付フランジ、固定案内、スライディングスリーブ、支持球、転がり軸受レース、3本のサーボ、回り止め/回転駆動、ハブ、5個の翼根モジュールを別部品として持つ。BOMの `Connection` と `EngineeringNote` は接続先と未検証容量を示すが、工具アクセス、ピン抜去、軸受交換、締結トルク、調整値、サービス姿勢を実証した組立手順ではない。`TiltSocket` の2 mm隙間は表示用で、組立公差や実用クリアランスではない。

## 7. G1ブロッカーと次の検証

1. 翼・カフ・折畳みロック・内外レースを含む質量、CG、慣性をCADと一致させる。
2. 運用回転数、温度、密度、操縦域、停止/始動/ホバー/収納遷移の同時性を凍結する。
3. 材料、製法、温度条件、スクリーニング許容値を出典付きで設定し、ピン・リンク・レース・エラストマー・継手の容量/疲労/面圧を計算する。
4. 球面軸受の6成分剛性/減衰、ラグダンパーの温度・速度特性、正常/劣化/無ダンパーの単翼応答を保存する。
5. CAD検証済み範囲を拡大し、根元ロック/タン、ヘッド、リンク、機体包絡を含む部品対隙間と折畳み経路をJSON/CSVで保存する。
6. 折畳みヒンジ・飛行ロックの途中経路、復帰、残留回転インターロック、工具アクセスを実形状で確認する。
7. ダンパー係数は暫定仮定のため、温度/速度依存モデルと全機連成を追加検証する。現行の複合感度ζ=0.0424は暫定目標を上回るが、容量・耐久の証明ではない。

この候補は、有限リンクの数値閉路と構成説明を前進させるためのものだが、構造定格と全域CAD検証がない限りG1/G2/G3を通過しない。
