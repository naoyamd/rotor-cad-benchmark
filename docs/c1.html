MECHANISM機構

How the swashplate worksスワッシュプレートの仕組み

The swashplate transfers fixed-side control input to the rotating side. Move the mechanism-mode sliders to see three relationships.スワッシュプレートは、固定側の操縦入力を回転側へ渡す仕組み。機構モードのスライダーを動かすと、3つの関係が見えてきます。

01

Change all five blade angles together5枚の翼角をまとめて変える

Raise collective and the ring rises. Constant-length pitch links push the horns, increasing all five blade pitch angles together.コレクティブを上げるとリングが上昇。一定長のピッチリンクがホーンを押し、5枚の翼のピッチ角が一緒に増えます。

02

Change blade angle with rotation position回転位置に応じて翼角を変える

Cyclic tilts the ring. Each blade passes through high and low sides while rotating, changing pitch by azimuth. Airframe response direction is outside this mechanism calculation.サイクリックはリングを傾けます。回転中の各翼は高い側と低い側を通り、方位に応じてピッチが変わります。機体の応答方向はこの機構計算の対象外です。

03

Fold the blades翼を折り畳む

A candidate for removing the flight lock and folding each blade in the stopped, parked posture. In the saved CAD state, width is reduced from the 18.60 m diameter to about 3.504 m.停止・駐機姿勢で飛行ロックを抜き、各翼を折り畳む候補。CADの保存状態では、横幅を18.60 mの直径から約3.504 mへ抑えています。

Real CAD vs. explanatory model実CADと解説モデルの区別

The real CAD mode triangulates saved FCStd with 3 mm linear and 0.35 rad angular deviation. It displays 145 parts excluding the airframe reference envelope. The operation mode is simplified geometry using the same mechanism coordinates and link solution; it is not CAD for interference checks.実CADモードは保存済みFCStdを線形偏差3 mm・角度偏差0.35 radで三角形化。機体参照包絡を除く145部品を表示。操作モードは同じ機構座標とリンク解を使った簡略形状で、干渉判定用CADではありません。

Independent three inputs, component structure, connection relationships, and verification materials are published. This is not a replica of a real AW101.独立した3入力、構成部品、接続関係、検証資料を公開。実機AW101の複製ではありません。
