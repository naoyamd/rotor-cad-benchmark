HOW TO COMPARE

How to interpret this comparisonこの比較で分かること

This comparison traces the mechanism and geometry changes made in response to C1's problems. Improvements alone do not count as a pass when a requirement remains incomplete.C1の問題を受けて、C2で機構や形状がどう変わったかを追えます。ただし、改善した箇所があっても要求全体を満たさなければ合格にはしていません。

To compare CAD implementation alone across AI systems, the evaluator must provide the same completed design basis to each system. Neither C1 nor C2 shown here has passed G1.別のAIとCAD実装だけを比べる場合は、完成済みの設計基準を評価者が用意し、同じ版を渡す必要があります。ここに掲載したC1・C2のG1はいずれも未通過です。
