HOW TO COMPARE

この比較で分かること

C1の問題を受けて、C2で機構や形状がどう変わったかを追えます。ただし、改善した箇所があっても要求全体を満たさなければ合格にはしていません。

別のAIとCAD実装だけを比べる場合は、完成済みの設計基準を評価者が用意し、同じ版を渡す必要があります。ここに掲載したC1・C2のG1はいずれも未通過です。
